Date: 2026-05-21

Full shell replacement implemented:
- Ported the OLED/local mockup into the real app shell instead of keeping the old UI structure alive.
- Header is now local-first: WorldWideView Local, search, Map, Layers, Cache, Settings, and theme.
- Removed the old top status pills and the visible LIVE/status badge treatment.
- Removed visible region preset strip, time-window dropdown, and API key modal entry from the header.
- Left panel is now the primary workspace with browser-style Data, Imagery, and Plugins tabs at the top.
- Settings opens inside the left panel from the header, with GeoJSON import and diagnostics/status cards.
- Left and right side panels remain resizable and collapsible.
- Right panel is now a contextual inspector only. Old Intel/Filters/Overlay/Settings tabs are no longer visible.
- Inspector shows selected entity or highlighted layer status, feed description, and key-value metadata.
- Bottom timeline keeps the original timeline component, but collapsed mode now shows two pills: Timeline and coordinates.
- When the bottom panel is hidden, both side panels stretch down to the bottom of the viewport.
- Desktop camera stats HUD and mobile HUD strip are hidden; coordinates now live beside the timeline pill.
- Enabled feed toggles use the green active state, while feed icons still come from the app PluginIcon path.

Known follow-up / intentionally not ported into the visible shell yet:
- The old full filter editor is not exposed in the new right panel.
- Plugin overlay/configuration components are not exposed in the new right panel.
- API Keys need a new Settings home if we still want them visible.
- Favorites/saved items need a new home.
- Feedback is no longer in the visible inspector shell.
- Marketplace browsing still exists inside Plugins; decide whether to hide it behind Advanced for this local fork.
- Region presets and time-window controls are not in the new header. Add them back only if they get a cleaner local-shell home.
- Civil aviation can still show zero entities when OpenSky credentials/local feed data are missing. The inspector now makes the no-data state explicit.
- A runtime request to `http://localhost:5000/manifest` still fails when the local engine is not running. That is separate from this UI port and should be handled in the local engine/diagnostics phase.
